# Documentation

Everything you need to run 9t, in six short pages. Start with install,
then pair your phone.

- **[Install](/docs/install/)** — start-here 3-liner, local / LAN / public modes, preferences, Docker, updates, recovery.
- **[Android](/docs/android/)** — install the APK, pair from the phone or paste a code, screens, background receiving.
- **[Network](/docs/network/)** — pick the right address, WSL port forwarding, hotspots, fix-it-in-order table.
- **[Sharing](/docs/sharing/)** — expiring public links, passwords, access counts, revocation, QR handoff.
- **[Operations](/docs/operations/)** — backups, CLI, systemd service, update flow.
- **[Principles](/docs/principles/)** — what 9t is, what it refuses to become, and the roadmap.

> The markdown originals live in the repo under [`docs/`](https://github.com/M3264/9t/tree/main/docs).
> Found a mistake? Open a pull request — docs fixes are the easiest first contribution.
