1 · Install

Start here.

In your Linux/macOS terminal, or Ubuntu inside WSL on Windows:

git clone https://github.com/M3264/9t.git
cd 9t
./setup.sh

Choose LAN if your phone will connect over Wi-Fi or a hotspot. Keep the printed port and startup instructions, open the address, sign in with the administrator you created, then follow the network guide. On Windows/WSL, complete the forwarding steps there before using the address on your phone.

The download/build needs internet. After installation, a running LAN server exchanges data with the Android client without internet access. Requirements: Node.js 22+ (the wizard installs a local copy under .tools/node if missing and you agree).

Modes: local, LAN, public

ModeBinds toUse when
Local127.0.0.1This computer only.
LAN (default)0.0.0.0, login still requiredPhone and other devices on the same network should reach it. Does not distinguish trusted Wi-Fi from other reachable interfaces — on a cloud host, use its firewall.
Public127.0.0.1 behind your same-host HTTPS proxyYou already run an HTTPS reverse proxy (e.g. Nginx + Certbot). Set NINE_T_HTTPS=true so session cookies get the Secure flag.

Auth is mandatory in every mode. To change the binding later, edit NINE_T_HOST and PORT in .env.production and restart — do not rerun setup.

Unattended installs: ./9t setup --answers /path/to/preferences.json --yes (password via NINE_T_ADMIN_PASSWORD env, never in the JSON). Preview with --dry-run; pre-flight checks with ./9t setup --check.

Docker alternative

Requires Docker Engine with Compose v2. Data persists in the 9t-data volume; the phone event socket shares port 3265.

git clone https://github.com/M3264/9t.git
cd 9t
NINE_T_SETUP_TOKEN=$(openssl rand -hex 16) docker compose up -d --build

Open http://<host>:3265 and create the administrator in the browser. Behind an HTTPS proxy add NINE_T_HTTPS=true. Update with git pull then docker compose up -d --build; back up with docker compose exec 9t node scripts/backup.mjs.

Updates

./9t status     # service state, build presence, listener + initialized flag
./9t update      # backup, git pull, rebuild into staging, migrate, restart

update refuses when the working tree has local changes and backs up data first. start warns when sources are newer than the running build — that usually means an update was pulled but not rebuilt.

Recovery

  • The installer never overwrites an existing data directory, config, or service for the checkout.
  • Key files: .env.production (private env), data/9t.json (admin, modules, workspace data), .9t-install.json (install summary), .9t/ (generated proxy/service files).
  • If a build fails, fix the displayed error and retry; if config was saved, resume with ./9t start.
  • Systemd units are named 9t-<checkout-hash>.service. Diagnose with sudo systemctl status NAME and sudo journalctl -u NAME -f.
  • Stop the service before moving or removing its checkout. Back up data before any update or restore.
